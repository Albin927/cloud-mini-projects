# Linux Mini Projects

This repository contains two Linux mini projects completed to practice Linux command-line operations, file management, and text processing.

## Project 1 – Basic File Operations

- Created files and directories
- Added and viewed file contents
- Practiced basic Linux file management commands

## Project 2 – Linux Search and Text Processing

- Searched for files recursively
- Counted files and directories
- Found text within files
- Identified duplicate and unique words
- Practiced text processing using Linux commands

## Skills Learned

- Linux Command Line
- File Management
- Text Processing
- Shell Utilities
- Command-Line Navigation
