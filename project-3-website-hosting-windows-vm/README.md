# Website Hosting using Windows VM

## Overview

This project demonstrates hosting a template website on a **Windows-based Virtual Machine (VM)**.

The main objective was to understand the basic process of deploying website files to a virtual machine, configuring the VM for web hosting, and accessing the hosted website through its public IP address.

> **Note:** The website used in this project is a template website used for practicing the hosting and deployment process.

---

## Objective

The objectives of this project were:

* Understand the basics of Virtual Machines
* Create and configure a Windows VM
* Deploy a website to the VM
* Configure the VM for web access
* Access the hosted website using the VM's public IP address
* Gain practical experience with cloud-based website hosting

---

## Technologies Used

* Windows Virtual Machine
* HTML/CSS Website Template
* Web Server / Web Hosting Configuration
* Public IP Address
* Web Browser

---

## Implementation Overview

The project followed the general workflow:

```text
Website Template
       ↓
Windows Virtual Machine
       ↓
Web Server Configuration
       ↓
Website Deployment
       ↓
Public IP Address
       ↓
Web Browser
```

The website files were deployed to the Windows VM and configured so that the website could be accessed externally through the VM's public IP address.

---

## Website

The hosted website was a pre-existing template website used to demonstrate the hosting process rather than a custom-developed web application.

The purpose of the project was primarily to gain practical experience with:

* Virtual machine deployment
* Server configuration
* Website deployment
* Network accessibility
* Accessing a hosted website through a public IP

---

## Result

The website was successfully hosted on the Windows VM and accessed through its public IP address using a web browser.
