# Project 12: Azure Log Analytics Workspace

## Objective

Created and configured an Azure Log Analytics Workspace to provide centralized collection and analysis of monitoring data.

## Azure Services Used

- Azure Log Analytics Workspace
- Azure Monitor
- Kusto Query Language (KQL)

## Implementation

1. Created a Log Analytics Workspace named `SecurityLogger`.
2. Configured the workspace in the Azure environment.
3. Verified that the workspace was active.
4. Used the Logs interface to query collected monitoring data.

## Key Concepts Learned

- Log Analytics Workspace
- Azure Monitor
- Centralized logging
- KQL
- Log collection and analysis

## Result

Successfully created the `SecurityLogger` Log Analytics Workspace and accessed its Logs interface for analyzing collected events.
