# Project 2 – Linux Search and Text Processing

## Objective

Practice searching, filtering, and processing files and text using Linux commands.

## Commands Used

- find
- grep
- wc
- sort
- uniq
- tr

## Tasks Performed

- Counted all `.txt` files recursively.
- Searched for files containing the word "Linux".
- Counted directories.
- Searched for files containing specific keywords.
- Identified duplicate words.
- Listed unique words from text files.
