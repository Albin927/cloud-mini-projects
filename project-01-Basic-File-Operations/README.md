# Project 1 – Basic File Operations

## Objective

Learn the fundamentals of file and directory management using Linux commands.

## Commands Used

- cd
- touch
- echo
- cat
- ls

## Tasks Performed

- Created a text file.
- Added multiple lines using the `echo` command.
- Displayed file contents using `cat`.
- Verified the output using the terminal.
