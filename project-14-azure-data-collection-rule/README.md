# Project 14: Azure Data Collection Rule for Failed Login Events

## Objective

Created an Azure Monitor Data Collection Rule (DCR) to control the collection of monitoring data from a Windows environment.

## Azure Services Used

- Azure Monitor
- Data Collection Rules
- Log Analytics Workspace
- Windows VM

## Configuration

A Data Collection Rule named:

`FailedLogins`

was created for collecting monitoring data from the Windows environment.

## Key Concepts Learned

- Data Collection Rules
- Data sources
- Data collection
- Azure Monitor
- Log Analytics
- Windows event monitoring

## Purpose

The DCR provides a controlled way to define which monitoring data should be collected and where that data should be sent.

## Result

Successfully created the `FailedLogins` Data Collection Rule and configured it for monitoring.
